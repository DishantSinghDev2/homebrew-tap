# Homebrew tap for BuyProxy

```bash
brew install DishantSinghDev2/tap/buyproxy
```

Installs the [BuyProxy CLI](https://github.com/DishantSinghDev2/buyproxy-cli) — generate residential, mobile, ISP and datacenter proxies from your terminal.

Formulae in this tap are updated automatically by the CLI's release workflow.

| Formula | Description |
|---|---|
| `buyproxy` | BuyProxy command-line tool |

Website: <https://www.buyproxy.org>
